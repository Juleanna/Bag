# 🚀 BugTracker Frontend - Быстрый старт (5 минут)

## 📋 Требования

Перед началом убедитесь, что установлены:

- **Node.js 18+** → [скачать](https://nodejs.org/)
  ```bash
  node --version  # Проверить версию
  ```
- **npm 11+** (идёт вместе с Node.js)
  ```bash
  npm --version   # Проверить версию
  ```

## 🎯 Шаг 1: Установка (1 мин)

```bash
# Перейти в папку frontend
cd c:\Bag\frontend

# Установить все зависимости (npm, Vite, Tailwind, DaisyUI, и т.д.)
npm install
```

**Ожидание:** Это может занять 2-3 минуты на первый раз.

## 🔌 Шаг 2: Запуск Django (1 мин)

Откройте **новый терминал** и запустите:

```bash
# Перейти в корневую папку проекта
cd c:\Bag

# Запустить Django сервер
python manage.py runserver
```

Вы должны увидеть:

```
Starting development server at http://127.0.0.1:8000/
```

**Важно:** Оставьте этот терминал открытым!

## 🎨 Шаг 3: Запуск Vite (1 мин)

В **первом терминале** (в папке frontend) запустите:

```bash
npm run dev
```

Вы должны увидеть:

```
➜  Local:   http://localhost:5173/
➜  press h to show help
```

**Браузер откроется автоматически!** ✨

## ✅ Шаг 4: Проверка (2 мин)

Если вы видите приложение в браузере на `http://localhost:5173`:

- ✅ **Работает!** Приложение полностью готово к разработке

### Что вы видите?

- 🧭 **Навбар** с кнопками "Проекты" и "Задачи"
- 📦 **Список проектов** (или пусто, если нет данных)
- ➕ **Кнопка "Новый проект"** для создания

## 📱 Тестирование функций

### Создать проект

1. Нажмите **"➕ Новый проект"**
2. Введите название и описание
3. Нажмите **"Создать"**
4. Вы должны увидеть проект в списке

### Открыть проект

1. Кликните на карточку проекта
2. Должны появиться задачи проекта (сейчас пусто)
3. Нажмите **"← Назад к проектам"** чтобы вернуться

### Создать задачу

1. В проекте нажмите **"➕ Новая задача"**
2. Введите название, описание и приоритет
3. Нажмите **"Создать"**
4. Задача появится в списке

## 🐛 Типичные проблемы

### ❌ Ошибка: "Cannot find module 'vite'"

```bash
# Решение: переустановить зависимости
rm -rf node_modules package-lock.json
npm install
```

### ❌ Ошибка: "Port 5173 already in use"

```bash
# Решение 1: Использовать другой порт
npm run dev -- --port 3000

# Решение 2: Завершить процесс на порте 5173
# В Windows PowerShell:
netstat -ano | findstr :5173
taskkill /PID <PID> /F
```

### ❌ Ошибка: "Connection refused (localhost:8000)"

```bash
# Решение: Убедиться, что Django запущен
# В отдельном терминале:
cd c:\Bag
python manage.py runserver
```

### ❌ Страница белая / 404 ошибка

```
Решение: Очистить кэш браузера (Ctrl+Shift+Delete)
```
